# MEHMET – Hammam at Turkuman

**RTS-RPG Hybrid Prototype**  
Türkischer MİT-Kommando in Syrien – Hardcore Gore

## Setting
- Ort: Hammam at Turkuman (Hammam et-Turkman), Gouvernement ar-Rakka, Syrien  
  Koordinaten ca. 36.53°N 39.07°E
- Verdeckte Nachtmission
- Gegner: ISIS-Terror-Miliz
- Protagonist: Astsubay Üstçavuş Mehmet (MİT + Özel Kuvvetler)

## Controls
- **WASD** / Pfeiltasten – Bewegen
- **Maus** – Zielen
- **Linksklick** – Schießen
- **R** – Nachladen

## Features (aktueller Prototype)
- Top-Down 2D Nacht-Ansicht
- Spielbarer Mehmet mit originaler MPT-76
- 10 Squad-Mitglieder nach Fallschirmabsprung (sammeln)
- Hardcore Gore-System (Blut + Körperteile)
- RPG-Basis: Level, XP, Türkische Lira (TL)
- Feinde mit Patrol / Chase / Attack AI
